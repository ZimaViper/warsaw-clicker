WARSAW VIPER / WARSAW CLICKER — Mini App starter

1. Откройте index.html в браузере, чтобы посмотреть макет.
2. Это пока демонстрационный интерфейс: баланс и энергия не синхронизированы с ботом и не сохраняются на сервере.
3. Для запуска Telegram Mini App нужен HTTPS-адрес (например, GitHub Pages).
4. Не вставляйте токен бота в index.html и никогда не публикуйте его.
5. После публикации подключим URL к кнопке меню бота и сделаем серверную проверку Telegram initData, чтобы игроки не могли подделывать баланс.
